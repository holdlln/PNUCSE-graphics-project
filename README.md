# Between — 디자인 초안 01

`dist/index.html`을 브라우저에서 열면 됩니다. 온라인 미리보기에서는 같은 dist 폴더를 정적 서버로 제공합니다.

이름·자기소개·작품·역할·링크는 아직 전달받지 않아 임시 콘텐츠로 명시했습니다. 두 작품은 실제 수행 이력이 아닌 디자인 샘플입니다.

## 디자인 결정
- Spencer Gabor: 큰 타이포그래피와 작품 이미지 중심의 구성. Apple: 절제된 탐색과 넓은 여백. 부산국제록페스티벌: 색의 활력과 음악 삽입. 외부 작품 이미지는 복제하지 않았습니다.
- 게슈탈트 근접: 이미지, 제목, 설명, 과정 소개를 한 작품 단위로 묶고 작품 사이를 넓게 설정.
- 시각적 위계: 첫 화면의 문구와 대표 비주얼을 중심으로 구성, 오렌지는 주요 포인트에 제한.
- 피츠의 법칙: 메뉴 44px 높이, 작품 이동 51px 원형 링크, 설명 펼치기 넓은 클릭 영역.
- 대비와 중복 단서: 본문은 어두운 글자, 링크는 텍스트와 밑줄, 펼침은 + 및 열린 상태 표시.
- 모바일: 700px 이하에서 한 열로 재배치, hover 없이도 내용을 읽고 조작 가능.
- 폰트: DM Sans, Instrument Serif, Noto Sans KR. Google Fonts 연결 실패 시 로컬 대체 글꼴 적용.

## AI와 외부 콘텐츠
- Codex: 레퍼런스 확인, 화면 설계, HTML/CSS, 반응형 및 검증.
- ImageGen: 은빛 리본/오렌지 구체 콘셉트 이미지 1개 생성. 실제 사용자 작품이 아님.
- Spotify: 부산국제록페스티벌 공개 플레이리스트를 샘플로 삽입. 사용자 목록으로 교체 예정. 자동 재생하지 않음. 네트워크 및 Spotify 정책에 따라 로그인 또는 미리듣기 제한이 있을 수 있음.
- 사용자 직접 수정 및 동료 관찰: 아직 진행하지 않음. 실제 수행 이후 기록할 것.
